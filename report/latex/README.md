# Building the report

## What is generated and what is not

| Path | Generated? | Edit this |
|---|---|---|
| `../ch*.md` | no | **yes, this is where the report is written** |
| `chapters/ch*.tex` | **yes, by `md2tex.py`** | no, your edits will be overwritten |
| `chapters/front/*.tex` | no | yes, by hand |
| `chapters/back/*.tex` | no | yes, by hand |
| `main.tex` | no | yes, by hand |
| `hcmut-thesis.cls` | no | **never.** See below |

## hcmut-thesis.cls

This file is the faculty template's own, byte for byte, copied from
`C:\Project\Specialized-Project-Template-EN\`. It is never modified. Anything
the report needs goes in `main.tex`'s preamble instead, so that the cover page,
the margins and the labels in the submitted PDF are the faculty's and can be
shown to be.

Verify at any time:

```
diff C:/Project/Specialized-Project-Template-EN/hcmut-thesis.cls hcmut-thesis.cls
```

## Build

`pdflatex` is not on PATH. It lives at:

```
C:\Users\USER\AppData\Local\Programs\MiKTeX\miktex\bin\x64
```

From this directory, in PowerShell:

```powershell
$env:PATH = "C:\Users\USER\AppData\Local\Programs\MiKTeX\miktex\bin\x64;$env:PATH"
python -I md2tex.py
pdflatex -interaction=nonstopmode main.tex
bibtex main
pdflatex -interaction=nonstopmode main.tex
pdflatex -interaction=nonstopmode main.tex
```

Three `pdflatex` passes, because the table of contents, the list of figures and
the cross-references each need a pass to settle.

## Checking the build

Exit code 0 is not enough. LaTeX reports many problems as warnings and still
exits clean.

```powershell
$log = Get-Content main.log -Raw
"LaTeX errors:         " + ([regex]::Matches($log,'(?m)^!\s')).Count
"Undefined references: " + ([regex]::Matches($log,'LaTeX Warning: Reference .* undefined')).Count
"Undefined citations:  " + ([regex]::Matches($log,'LaTeX Warning: Citation .* undefined')).Count
"Overfull hboxes:      " + ([regex]::Matches($log,'Overfull \\hbox')).Count
```

All four should be 0.

## Markdown the converter understands

`md2tex.py` is written for this report, not for Markdown in general, and fails
loudly on anything else. That is deliberate: a document that compiles once and
is checked by eye is better served by a converter that stops than by one that
guesses.

| Markdown | Becomes |
|---|---|
| `# Chapter 4 - Design Decisions` | `\chapter{...}` plus `\label{chap:4}` |
| `## 4.2 Target Device` | `\section{...}` plus `\label{sec:4.2}` |
| `### 4.2.1 Options` | `\subsection{...}` plus `\label{sec:4.2.1}` |
| `### Anything else` | `\subsection*{...}`, unnumbered |
| `#### Anything` | `\subsubsection*{...}`, unnumbered |
| `![short name](fig-4-1-name.png)` | a `figure`, with `.png` rewritten to `.pdf` |
| `**Figure 4.1** caption` on the next line | that figure's caption and `\label{fig:4.1}` |

**Write the alt text as a short figure name, not as the caption again.** It
becomes the optional argument of `\caption`, which is what the List of Figures
prints, while the `**Figure N.N**` paragraph becomes the caption under the
figure. Three or six words is right: "Use cases of Module 1, the training
session". If the alt text is empty or identical to the caption, one caption is
emitted and the List of Figures gets the whole sentence, which is what it used
to do for every figure and is why the list ran to three lines an entry.
| a pipe table | a `longtable`, column widths from the longest cell |
| a fenced code block | `lstlisting` |

Section numbers written in the Markdown are **stripped and regenerated by
LaTeX**. The prose refers to sections by literal number, so the two must agree.
Check after every build that they still do.

## Figures

`graphics/` is what LaTeX reads, and `figures/render.py` copies every PDF it
renders into it. That copy used to be manual, as a gate so that no figure
reached the report without being looked at. The gate turned into a defect:
three figures were redrawn and the built PDF went on showing the old ones,
because nobody remembered to copy them. The looking happens at render time
now, where the output names every file it wrote.

The two UI assets, `forma-brand.png` and `forma-screens.png`, are exported
from Figma into `docs/assets/ui/` and still have to be copied here by hand
after a re-export.

The Markdown references `fig-*.png` and `md2tex.py` rewrites the extension to
`.pdf` during conversion, so the submitted PDF carries vector figures and
nothing has to be changed by hand in two places.
